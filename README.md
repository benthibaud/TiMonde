# TiMonde 📻✨
> *The small world of radios from anywhere — Le p'tit monde des ondes à portée de clic.*

**TiMonde** est un lecteur de webradios ultra-léger, minimaliste et discret, conçu pour se loger élégamment dans la zone de notification (systray / barre des tâches) des environnements Linux modernes.

Inspiré par l'esprit historique de **Radio Tray**, TiMonde le revisite pour offrir une expérience fluide, frugale et sans fioriture : le monde entier des ondes musicales et d'information concentré dans un mouchoir de poche.

---

## 🎯 Philosophie & Principes

- **🍃 Frugalité & Low-Tech :** Démarrage instantané, empreinte mémoire dérisoire, consommation CPU quasi-nulle.
- **🤫 Discrétion absolue :** Aucune fenêtre envahissante. Une icône claire dans le tableau de bord, un menu direct, la musique démarre.
- **💡 Évidence ("Obviousness") :** Validé sous l'œil intraitable de l'agente **BB** : zéro jargon, zéro configuration obscure, tout doit être utilisable immédiatement en totale autonomie.
- **🐧 Intégration Linux native :** Support moderne des standards du bureau (StatusNotifierItem / AppIndicator, X11 et Wayland).
